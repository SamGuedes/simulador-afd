SIMULADOR DE AFD

Como executar no Windows
1. Instale o Python 3 com Tkinter.
2. No GitHub, use Code > Download ZIP e extraia a pasta.
3. Dentro da pasta, digite cmd na barra de endereço e pressione Enter.
4. Execute: python simulador.py
5. Digite aba no campo Sentença. Clique em Próximo passo para ler
   uma letra por vez, ou em Executar até o fim para obter o resultado.

Arquivos do projeto
simulador.py — programa com interface gráfica que simula o AFD.
exemplo.json — estados, alfabeto, inicial, finais e transições.
Manual.txt — instruções de uso e testes.

Regra do exemplo
Usa somente as letras minúsculas a e b. Aceita entradas que terminam em a.
Estado inicial: nao_termina_em_a.
Estado final: termina_em_a.
Ao ler a, vai para termina_em_a. Ao ler b, vai para nao_termina_em_a.
A aceitação é verificada somente depois de ler a entrada inteira.

Testes com exemplo.json
Entrada       Resultado    Motivo
aba           Aceita       Termina em a.
ba            Aceita       Termina em a.
a             Aceita       Termina em a.
ab            Rejeitada    Termina em b.
bb            Rejeitada    Termina em b.
Campo vazio   Rejeitada    O estado inicial não é final.
abc           Rejeitada    A letra c não pertence ao alfabeto.

Passos para aba
Início: nao_termina_em_a
Lê a: nao_termina_em_a -> termina_em_a
Lê b: termina_em_a -> nao_termina_em_a
Lê a: nao_termina_em_a -> termina_em_a
Fim: Aceita.

Para testar a sentença vazia, deixe o campo vazio e execute até o fim.
Alterar a sentença ou clicar em Reiniciar começa a simulação novamente.
Para usar outra regra, edite uma cópia do JSON e abra pelo botão
Abrir arquivo JSON. O programa valida o arquivo antes de usá-lo.
